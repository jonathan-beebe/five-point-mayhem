## 2026-10-07 · Decided on five worlds on one map, each world modular

Decided to build a world past each of the five landmarks, reached through a pass in the mountain
rim, all on the one existing map. Required each world's code to be self-contained so it could move
to its own place if one map failed on server memory or player density.

Chose one map because the design depended on one continuous line of sight from the lobby through
the pass to the world, and vehicles, weapons and players carried across with no teleport. Weighed
five separate places as the alternative.
